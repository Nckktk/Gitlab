ชื่อโครงงาน : DC Circuit Calculator
คำอธิบาย: วัตถุประสงค์เพื่อพัฒนาโปรแกรมคำนวณวงจรไฟฟ้ากระแสตรง (DC) สำหรับหาค่ากระแสไฟฟ้าและกำลังไฟฟ้าของวงจรตัวต้านทาน ช่วยลดเวลาในการคำนวณด้วยมือและเพิ่มความแม่นยำในการวิเคราะห์วงจรพื้นฐานได้อย่างรวดเร็ว

## วิธีใช้งาน

รันโปรแกรมด้วย Python:

```powershell
python electrical.py
```

กรอกแรงดันไฟฟ้า (V) และความต้านทาน (ohm) เมื่อโปรแกรมถาม จากนั้นโปรแกรมจะแสดงกระแสไฟฟ้า (A) และกำลังไฟฟ้า (W) โดยความต้านทานต้องมากกว่าศูนย์
